# NYS — Not Your School

A clean, interactive four-year roadmap for students preparing for a software or IT career. The page focuses on the learning journey from college fundamentals to job readiness—without dashboards or progress-tracking clutter.

## Roadmap

- **Year 1 — Fundamentals:** programming, problem solving, and web basics
- **Year 2 — Programming + DSA:** data structures, algorithms, and core computer science
- **Year 3 — Projects + Internship:** full-stack projects, portfolio work, and internship preparation
- **Year 4 — Job Ready:** system design, interview practice, and placement preparation

Each year includes expandable semester details. The page also features example projects and a final call to action.

## Preview locally

No build step or package installation is required. Open `code.html` in a browser. Tailwind CSS is loaded from its CDN, so an internet connection is needed for the styling CDN to load.

## Built with

- HTML, CSS, and native `<details>` elements
- Tailwind CSS CDN
