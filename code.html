Year 1

FUNDAMENTALS

Build the technical base through programming fundamentals, logic, web basics and problem-solving confidence.

Programming Logic Building HTML CSS JavaScript
Explore Year

Semester 1

Choose one primary language and get comfortable writing small programs. Learn how to break a problem into steps, use variables, conditions, loops and functions, and practise clear explanations.

  • Programming
  • Logic
  • CS Basics
  • Problem Solving

Semester 2

Create and publish your first responsive website. Learn semantic HTML, CSS layout, JavaScript basics and Git workflows; document what you build in a simple README.

  • HTML
  • CSS
  • JS
  • GitHub
01Write small programs independently and explain your approach.
02Publish a responsive personal or college-club website.
03Use Git to save work and maintain a clear project README.
Year-end proof: a public website and a consistent set of beginner programs in GitHub.
Year 2

PROGRAMMING SKILLS + DSA

Strengthen core coding ability by learning DSA, algorithms, recursion, trees, graphs and essential CS theory.

C++ Python Arrays Graphs DP LeetCode
Explore Year

Semester 3

Practise complexity analysis and the core data structures: arrays, strings, hash maps, linked lists, stacks, queues and trees. Build a regular problem-solving habit.

  • DSA
  • Arrays
  • Strings
  • Linked Lists

Semester 4

Learn recursion, searching and sorting, graphs and introductory dynamic programming. Study OOP, DBMS, operating systems and networking alongside implementation practice.

  • Graphs
  • Recursion
  • DBMS
  • OS
01Solve problems by recognising patterns, not memorising answers.
02Explain time and space complexity and test edge cases.
03Build one small application that uses a database or external API.
Year-end proof: a structured DSA practice repository and a working application with a documented feature set.
Year 3

PROJECTS + INTERNSHIP

Apply your learning through full-stack projects, internship preparation and portfolio building with real-world proof.

Full Stack APIs GitHub Hackathons Resume Interviews
Explore Year

Semester 5

  • Full Stack
  • APIs
  • Backend
  • Databases

Year 4

JOB READY

Prepare for final placement rounds by revising advanced DSA, system design, mock interviews and job application strategy.

Advanced DSA System Design Mock Interviews Resume LinkedIn
Explore Year

Semester 7

Review important DSA patterns and core CS topics. Learn to clarify requirements, design a simple service and explain the trade-offs in your choices.

  • Advanced DSA
  • System Design
  • Core CS
  • Mock Interview

Semester 8

Tailor your resume for each role, practise technical and behavioural interviews, research employers and follow a steady, focused application routine.

  • LinkedIn
  • Aptitude
  • Applications
  • Placement Prep
01Explain your strongest projects, technical decisions and lessons learned.
02Complete realistic mock interviews and review gaps after each attempt.
03Apply to suitable software and IT roles with a tailored, honest application.
Year-end proof: a focused portfolio, interview-ready project stories, and a repeatable job search plan.
